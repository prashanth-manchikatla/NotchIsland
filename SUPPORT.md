# Getting help

- **How do I…? / Is this a bug?** Ask in [Discussions › Q&A](https://github.com/prashanth-manchikatla/NotchIsland/discussions/categories/q-a).
- **Found a bug?** Open a [bug report](https://github.com/prashanth-manchikatla/NotchIsland/issues/new?template=bug_report.yml).
- **Have an idea?** Share it in [Discussions › Ideas](https://github.com/prashanth-manchikatla/NotchIsland/discussions/categories/ideas).
- **Security issue?** Report it privately — see [SECURITY.md](SECURITY.md).

Before asking, it's worth checking the [feature tour](docs/features.md), the [build guide](docs/building.md)
(including troubleshooting) and the [FAQ](README.md#faq).
